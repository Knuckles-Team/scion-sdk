# SCION-SCM requirements

Governing spec: [spec.md](spec.md).

Each row is one requirement. A child row `.n` is one five-minute unit of work.
A row names the file it touches and the test that proves it. The generator
sets each row's state in `status.json`.

| `SCION-SCM-R001` | **Source client.** The SDK provides one typed client for the served `source.*` operations. It covers tree, blob, diff, history, blame, commit, land, and revert. A local bounded blob cache keyed by content digest backs blob reads. The connector or host composes the client; the SDK serves nothing itself. | Child rows R001.1 through R001.6 bind; `tests/test_source_client_served.py` proves the served path. |

| `SCION-SCM-R002` | **Virtual workspace mount (rollup).** Subsystem: SDK source client. The SDK mounts a sparse virtual workspace over the served `source.*` operations.
