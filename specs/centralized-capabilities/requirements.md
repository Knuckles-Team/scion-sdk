# SCION-CENTRALIZED-CAPABILITIES — Requirements

Governing spec: [spec.md](spec.md).

Each row is one centralized capability. A child row `.n` is one five-minute unit of work. A row names the module it covers and the check that proves it. The generator sets each row's state in `status.json`.
